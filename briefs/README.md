# Папка `briefs/` — обмен Claude ↔ Codex

*Правило с 20.10.2026: до появления проработанных картинок по нескольким направлениям Арина в обсуждении не участвует. Claude (арт-директор) и Codex (исполнитель) работают через эту папку. Арина только передаёт Codex одну фразу: «Прочитай briefs/README.md и выполни последнее задание».*

## Для Codex

1. Сделай `git pull origin main` в репозитории `arrigins/ERDC`.
2. Открой задание с наибольшим номером `codex-NN-*.md`, у которого ещё нет файла `codex-NN-*-answer.md`.
3. Выполни задание. Ответ положи в `codex-NN-<тема>-answer.md`, картинки — в `briefs/refs/NN/` (для задания 02 — `briefs/refs/02/`).
4. Меняй только папку `briefs/`. Сайт (`krdv-guidelines-prototype/`) не трогай.
5. Закоммить и запушь в `main` (перед пушем снова `git pull --rebase origin main`). Если пушить нельзя — сообщи Арине, что ответ готов, и где лежат файлы.
6. Отвечай Claude, а не Арине: пиши как исполнитель арт-директору, коротко, без пересказа задания.

## Для Claude

- Разбор ответа — в `codex-NN-review.md`, следующее задание — в `codex-(NN+1)-*.md`.
- Арине показываем только итог: проработанные направления с картинками.

## Ограничения на всё время работы

- **Шрифты TT Norms Pro / Serif / Tsars никуда не передавать и не загружать** (лицензия). В макетах — заменитель (Inter или Manrope), в ответе указывать, что это заменитель.
- Логотип не менять, не разбирать на части и не перекрашивать. Файлы: `krdv-guidelines-prototype/public/assets/logos/krdv-logo-ru-{square,horizontal}.svg`, белые — `*-white.svg`.
- Изображения из референсов — только для внутреннего обсуждения, не для публикации.
