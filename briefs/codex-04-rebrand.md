# Задание Codex №4: ребрендинг КРДВ — референсы бренд-систем (не логотипов)

## Контекст

- КРДВ меняет бренд. Это институт развития: помогает бизнесу и инвесторам (земля, льготы, инфраструктура, сопровождение). **Запрет «логотип не трогать» из README для этого задания не действует.**
- Режимы ТОР, СПВ и др. объединяются в **ЕТОР — единый режим поддержки**. ЕТОР — подбренд КРДВ, у него будут тысячи компаний-резидентов.
- Регионов около двадцати: весь Дальний Восток и Арктическая зона. Нужно уметь рассказывать про каждый.
- **Логотип вторичен.** Можно оставить упрощённый лотос. Ищем то, из чего строится полноценная система: архитектура, регионы, продукт, метки для партнёров, инструменты.
