Графика КРДВнаправление развития

Новую графику придумывать не нужно. В соцсетях КРДВ уже сложился сильный язык: синее поле, белое сообщение, метки и объёмный объект. Задача — назвать его элементы, закрепить правила и перенести на все носители: от презентации до стенда.

02 — Элементы

Восемь элементов системы

Каждый элемент описывается одинаково: что это, где уже работает, правила. Зелёная отметка — пункт уже согласован для брендбука.

Поле

Два фона, а не десять

Основной — насыщенный синий, дополнительный — молочный. Цвет режима — поле для материалов этого режима.

  • Внутри поля — только световой перепад того же цвета, без разноцветных пятен
  • Готовые фоны — файлами, а не «на глаз» каждый раз
  • Фото — отдельным окном на поле, а не подложкой под весь текст

Сообщение

Одна мысль крупно

Заголовок — главное на макете. Всё остальное ему подчиняется.

  • TT Norms Pro: Bold для заголовка, Regular для уточнения
  • По левому краю, без центровки и капса в длинных фразах
  • Шкала кеглей от стороны макета — задаётся сеткой (раздел 04)

Метки

Плашка — общий элемент соцсетей и наружки

Скруглённая плашка уже работает в постах и на билбордах СПВ. Её стоит закрепить как систему из трёх видов.

  • Коралловая — статус и срок, одна на макет
  • Полупрозрачная — уточнение на синем поле
  • Белая — призыв к действию, текст цветом поля
Объект

Один объёмный предмет — смысл сообщения

Два материала: глянец — для коммуникации (иконки портала, пузыри соцсетей), стекло — для режимов и программ.

  • Свет сверху слева, мягкая контактная тень, ракурс ¾
  • Один объект на макет, можно обрезать краем
  • Фирменные цвета, без обводок и нефирменных оттенков
✓ согласовано (Б5)
Крупный кроп

Буквы, которые не помещаются

Приём из мерча: «КР» и «ДВ» уходят за край предмета. Работает как суперграфика без логотипа.

  • Для мерча, стендов, сцены, обложек отчётов
  • Буквы — только КРДВ, без других слов
  • Не на одном макете с объектом: кроп — сам по себе главный герой
КРДВ.Заряжены на развитие
Подпись

«КРДВ. + фраза»

Сейчас живёт только на предметах. Становится фирменным завершением: последняя карточка поста, финальный слайд, подпись под билбордом.

  • «КРДВ.» — Bold, фраза — Regular, всегда две строки
  • Фраза короткая и с характером, по правилам «Как мы говорим»
  • Банк одобренных фраз — в брендбуке
✓ согласовано (Б6)
Пиктограммы

Плоский слой для навигации

Пиктограммы КРДВ в круге. Это плоская пара к объёмным объектам: навигация, списки, инфографика.

  • Одна сетка и толщина линии, круглая подложка
  • Пиктограмма и 3D-объект не смешиваются в одном блоке
  • Набор эмодзи для Telegram — из той же библиотеки
✓ согласовано (Б5)
Окно

Фото — в окне с направлением

На билбордах СПВ фото обрезано стрелкой вперёд, город — в круге. Стоит проверить, может ли это окно стать общим правилом для фото на синем поле.

  • Одна форма окна на кампанию
  • Фото по правилам «Фотостиля»
  • Вопрос к команде: закрепляем или оставляем приёмом СПВ
03 — Знаки режимов

Из 3D — в вектор

Старые линейные знаки выводятся из обращения. Единственная актуальная версия — объёмная. Из неё нужно собрать плоский вектор для документов, печати, мелких размеров и навигации.

Что собрать

Плоский знак по силуэту 3D: форма, пропорции и скругления — как у объёмного, внутренний объём — одним-двумя тонами цвета режима.

Версии

Цветная (на светлом) и белая (на цвете режима и фото). Минимальный размер — проверить на 16 и 24 px.

Форматы

SVG и PNG для экранов, PDF в CMYK для печати. Цвета — из утверждённой палитры направлений.

04 — Сетка

Один модуль на все форматы

В соцсетях модуль уже есть: отступ — 1/18 стороны, знак — 1/9. Предлагаю считать его от короткой стороны любого носителя. Тогда пост, сторис, слайд и роллап собираются по одному правилу.

Модуль

1/18 короткой стороны. Поля — один модуль, знак — два модуля.

Диагональ

Сообщение — слева сверху, объект или фото — справа снизу. Это даёт ритм и не даёт им спорить.

Кегли от модуля

Заголовок, уточнение и служебная строка — фиксированные доли модуля для каждого формата.

05 — Цвет

Палитра практики и палитра брендбука расходятся

Соцсети работают на ярком синем, коралловом и молочном — их нет в разделе «Цвет». Основной синий брендбука темнее и спокойнее. Нужно решение: утвердить «цифровую» пару официально или привести соцсети к основной палитре.

08 — Ограничения

Чего в системе нет

Разноцветные размытые пятнаФон — один цвет со световым перепадом, а не смесь оттенков.
Декоративные формы без смыслаВолны, лепестки, абстрактные фигуры «для красоты».
Старые линейные знаки режимовТолько объёмная версия и собранный из неё вектор.
Несколько объектов на макетеОдин герой. Остальное — метки и текст.
3D и пиктограммы в одном блокеОбъём и плоскость — разные слои, не смешиваются.
Цвета вне палитрыВключая «почти фирменные» оттенки синего.
